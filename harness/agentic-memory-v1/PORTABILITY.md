
# Support Engine · проверка переносимости Agentic Memory и User Context

Режим REUSABLE_PRODUCT. Объект проверки — жизненный цикл памяти, пользовательский контекст и их интеграция с NextShop. Контракт архитектуры описывает более широкий Support Engine. Общая переносимость остальных возможностей требует отдельного доказательства.

## Реализация и зависимости

| Граница | Файлы и ответственность |
| --- | --- |
| CORE | consultation-memory.core.ts, memory.contract.ts и memory.policies.ts содержат канонический снимок, TTL, сравнение ревизий, доступ и признаки продолжения. user-context.contract.ts содержит типы предпочтений, происхождения и будущего события. |
| APPLICATION / PORT | consultation-memory.application.ts, memory.port.ts и user-context.application.ts оркестрируют транзакции по предметным контрактам. Источник проверяет состояние сессии, принадлежность хода и факт ответа. Хранилище реализует атомарную запись эпизода и квитанции. |
| ADAPTER | NextShopMemorySource и NextShopUserContext переводят Chat, Message, роль и каталог в доменные значения. ChatGateway, ProductAgent и LangGraph интегрируют команды. Frontend форматирует критерии. Синтетический каталог ПК использует отдельные идентификаторы, доказательства хода и поля. |
| INFRASTRUCTURE | PrismaMemoryRepository и PrismaUserContextRepository используют PostgreSQL. Транзакция допуска потребляет предложение вместе с сообщением. Проекция после ответа использует короткую отдельную транзакцию. Явный отзыв предпочтения входит в транзакцию исправления или удаления эпизода. |
| STORE-OWNED | Каталог, цены, наличие и аккаунты остаются авторитетными в интеграции магазина. NextShop проверяет актуальные цену и остаток после Qdrant. Профиль и эпизоды принадлежат Engine. |

## portability-checklist.md

| Раздел | Статус | Свидетельство |
| --- | --- | --- |
| A · Core independence | PASS | Канонические контракты и приложение используют только свои типы и Zod. Импорты Prisma, Nest, NextShop, транспорта, Qdrant и AI находятся вне этих файлов. Отказ доступа/актуальности возвращается доменным результатом или типизированной ошибкой. |
| B · External integrations | PASS | NextShop и PC преобразуют разные идентификаторы, критерии и свидетельства источника. Общий прогон проверяет чужого владельца и магазин, отсутствующий источник, свежесть, дедупликацию, удаление и отказ записи. ProductAgent использует существующий поиск. Внешних мутаций каталога и синхронизации событий эта возможность не требует. |
| C · Client independence | PASS для затронутого контракта | Структурированные версии снимков и событий, аддитивные ответы Socket.IO и независимый HTTP API. Клиент не определяет права и ревизии. Сервер проверяет команды. Полная переносимость сессии, стриминга и маршрутизации Support Engine — NOT VERIFIED. |
| D · Data and infrastructure | PASS для памяти и профиля | PostgreSQL, изолированные Qdrant/Redis для NextShop и аттестация стенда. Engine API работает без frontend. Изоляция памяти и профиля проверена между владельцами и магазинами. Общий multi-tenant каталог NextShop в одном Qdrant-индексе — NOT VERIFIED. |
| E · AI processing | NOT APPLICABLE к Core памяти и профиля | Эти правила не вызывают модели. Детерминированный AI тестирует NextShop в браузере. Реальные провайдеры и переносимость индекса за пределами памяти — NOT VERIFIED. |
| F · Agentic Memory | PASS | Два источника с одним приложением и PostgreSQL, приостановка, TTL, удаление, повтор и конкуренция. Для ПК отсутствует связь с NextShop Chat. События магазина не нужны. |
| F · Product Consultant | PARTIAL | Проверены свежий поиск NextShop через реальный Qdrant и простое восстановление условий каталога ПК. Полный консультант ПК, обогащение, другие поставщики каталога и Review Intelligence — NOT APPLICABLE к этому изменению. |
| F · Review Intelligence / Order Agent | NOT APPLICABLE | Для Order Agent затронута только регрессия маршрутизации. Перенос его интеграций и Review Intelligence в этот этап не входит. |
| G · Required verification | PASS | Общий runner на двух независимых Prisma-соединениях. Один Core для обоих адаптеров, v1/v2, одноразовое продолжение, ролевая проверка, API и браузер. Сбои источника и записи не дают чужих данных или частично записанных предпочтений. |
| H · Final report | PASS для границы памяти и профиля | Этот отчёт, STATE и README содержат зависимость от NextShop, путь миграции, тесты и ограничения. |

| A · Продукт и контракт | PASS. Эпизоды и подтверждённые факты, доверенный контекст, версия, явные действия, документированный API. |

Команды: npm.cmd run build, node infra/integration/agentic-memory-portability.mjs, node infra/integration/agentic-memory.mjs, node infra/integration/agentic-memory-resume.mjs, целевой frontend Jest и Cypress Electron. Расширенный backend Jest выявил 3 набора, которые воспроизводимо падают и на неизменённой ревизии e4229ad. Это отдельный долг базовой ветки, сбоев в проверенных контрактах новой поставки нет.

Вердикт **PASS для Agentic Memory и User Context в согласованных границах**. Работа полноценного Support Engine с внешней торговой платформой, другой БД, production-нагрузкой и реальными AI-провайдерами этой проверкой не подтверждена.
