# Agentic Memory V1

Утверждено пользователем в чате для A0–A2 в режиме REUSABLE_PRODUCT. Backend baseline b23a3bb6ce0f9cc0a441cf499d4b1a61d6f77a16. Код Support Engine определяет текущие контракты.

## Покупательский сценарий

- Память доступна покупателю с аккаунтом. Гостевой чат работает без переноса истории в память. Подборы разделены по задаче Workspace. Новый подбор учитывает текущий запрос. Критерии прошлого подбора возвращаются только после явного продолжения.
- Эпизод содержит структурированные подтверждённые критерии, ссылки на рассмотренные, сравнённые и рекомендованные товары и подтверждённый исход. Выбор не считается покупкой. Пустая выдача и пауза не закрывают подбор. История разговора, рассуждения модели и устаревшие цена или остаток не копируются.
- При открытии чата после 7 суток без содержательной активности может появиться одно предложение продолжить незавершённый подбор. Reconnect возвращает то же действующее предложение. «Не сейчас» подавляет предложения на 7 суток. Та же ревизия содержимого повторно не предлагается.
- «Продолжить» возвращает критерии и одноразовую привязку для следующего явно продолженного хода. Клик не запускает поиск и не создаёт interrupt. Текущий бренд, цвет и бюджет имеют приоритет. Каталог проверяется заново.
- На 14-е сутки эпизод считается приостановленным. Через 90 суток с последнего подтверждённого содержательного действия эпизод скрывается и подлежит очистке. Показ и клики срок не продлевают.
- Владелец может просматривать, исправлять и удалять эпизоды через API. Удалённый эпизод не восстанавливается при retry, reconnect или чтении старого checkpoint. Отдельной панели управления нет.

## Граница доставки

Обычный ответ сохраняется и отправляется независимо от памяти. После публикации отдельная короткая транзакция применяет изменения памяти целиком либо откатывает их. Пропуск диагностируется. Изоляция по магазину и владельцу проверяется сервером. PostgreSQL является источником истины.

B — будущий User Context с нормализованными фактами, основаниями, версией, сроком и пересчётом при отзыве. C — будущий независимый ranker с портами каталога, контекста и Review Intelligence, где текущий запрос предшествует профилю. D — будущие отдельные адаптеры событий магазина. A0–A2 используют подтверждённые действия ProductAgent и Workspace.

## Приёмка

Реальные изолированные PostgreSQL и Qdrant, целевые регрессии, конкурентные проверки, управляемые часы и альтернативный адаптер источника. Ручная приёмка отдельно. Платные LLM-вызовы, рабочие сервисы и выпуск требуют отдельного разрешения.
