## Профиль и объём

- `CHAT_STANDARD=yandex-standard`, `YANDEX_MODEL=gpt://<folder-id>/yandexgpt-5.1`
  (YandexGPT Pro 5.1). Для поиска `EMBEDDING_PROVIDER=yandex`,
  `YANDEX_EMBEDDING_DOCUMENT_MODEL=emb://<folder-id>/text-embeddings-v2-doc/latest`,
  `YANDEX_EMBEDDING_QUERY_MODEL=emb://<folder-id>/text-embeddings-v2-query/latest`,
  `YANDEX_EMBEDDING_DIMENSIONS=768` по актуальной конфигурации. Ранее
  планировались `text-search-*` и 256 измерений. Существующие изолированные
  индексы детерминированного стенда созданы в синтетическом пространстве.
  Для реального корпуса нужна отдельная коллекция с зафиксированной
  версией модели и размерностью 768. Пресеты генерации для других
  провайдеров — `gpt-6.1-sol` и `qwen/qwen3.8-max`. Отключить fallback,
  автоматические повторы и фоновые вызовы.
                                                                                                                                                                                                                                                                                                    [Модели генерации](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models) · [Эмбеддинги](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/embeddings)
- Корпус из 12 коротких опубликованных отзывов. 10 разных авторов для
  товара A, 2 для B. Добавить черновик и отзыв с последующим отзывом
  публикации. Подготовить разметку подтверждённых достоинств, замечаний,
  отсутствующих ответов и релевантных источников до запуска.

| Сценарий | Ожидаемые вызовы | Критерии |
| --- | --- | --- |
| Summary | 1 генерация, `maxCalls=1` | Валидная схема. Все заявленные впечатления подтверждаются корпусом. Противоречащие мнения отражены. Порог 10 авторов соблюдён |
    | Review Q&A | 2 генерации и 2 query embeddings | Один точный вопрос и один вопрос с ограниченными свидетельствами. Вывод следует из показанных публикаций, формулировка своими словами. Нет недоказанной частоты или утверждения о свойствах товара |
| Recommendation | 2 генерации | С тем же фиксированным набором кандидатов запустить действующий синтез один раз с evidence и один раз с пустым evidence. Выбор опирается на каталог. Отзывы влияют на обоснование только там, где подтверждены |
| Retrieval и отзыв публикации | 12 document embeddings и 3 query embeddings | Вместе с запросами Q&A разметить 4 поисковых вопроса. Релевантный источник в top 3 хотя бы для 3 из 4. Дополнительный запрос после отзыва возвращает 0 отозванных, скрытых или чужих источников. Проверить размерность 768 и конечность компонент |

Всего ожидаются **до 5 генераций на провайдера и до 17 embedding-вызовов
на кампанию**. Разделить результаты поиска между провайдерами генерации
для одинаковых вопросов, переиспользуя подтверждённое Review Evidence.
Плановая оценка Яндекса
при 15 000 входящих и 2 500 исходящих LLM-токенах и 4 000 токенах
векторизации — **около 14,04 ₽**. Пределы на всю кампанию — 20 ₽ на
провайдера и 60 ₽ суммарно. На каждого LLM-провайдера максимум 20 000
входящих и 4 000 исходящих токенов, включая оплачиваемый reasoning.
Оценка Яндекса для этих пределов и плановых 4 000 токенов векторизации
составляет 19,2404 ₽ с НДС. Перед отправкой сверить применимый тариф.
[Тарифы Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing)

Считать вызовы на границе транспорта, записывать usage провайдера, модель,
latency, версию корпуса и решение по каждому критерию. Превышение бюджета
или любая утечка останавливает прогон. Для рекомендации использовать
зафиксированный контекст и существующий synthesizer. Планировщик и
reranker не включать в платный профиль.

### Ограничитель и условия запуска

- `infra/integration/live-ai-budget.mjs` сохраняет резерв до вызова
  транспорта в одном локальном журнале
  `.tmp/review-live-ai-campaign-v1.json`. Суммы хранятся в нанорублях.
  Эксклюзивная блокировка охватывает весь вызов. Ошибка транспорта или
  неопределённый usage сохраняют полный резерв и останавливают провайдера.
  Прерванный процесс требует сверки резерва с биллингом. Журнал
  инициализируется один раз после сверки предыдущих затрат кампании.
- `live-ai-http.mjs` использует один HTTPS POST на сценарий. Redirect,
  автоматические повторы и fallback отключены. Для текстового ввода
  верхняя оценка — байты UTF-8 сериализованного тела плюс запас на
  служебное форматирование. OpenAI `max_output_tokens` включает reasoning.
  Yandex использует `maxTokens` с отключённым reasoning. Polza пропускает
  запрос только если каталог маршрута Alibaba подтверждает
  `max_completion_tokens`, и вычитает 10 из лимита API на документированное
  отклонение. Usage проверяется по сумме input и output, reasoning
  хранится как часть output. Для OpenAI в резерве учтены верхний тариф
  записи кеша $5 / 1 млн input, $10 / 1 млн output, 100 ₽/$ и запас 30%.
- `live-ai-run.mjs offline` прошёл на настоящих PostgreSQL 15.18 и
  Qdrant 1.19.0 в `support-engine-it-a729e0d95671`. Подставной транспорт
  принял 5 генераций и 17 embeddings. Проиндексировано 12 синтетических
  отзывов для двух товаров. Поиск нашёл релевантный источник в top-3
  в 3 из 4 вопросов. Отзыв публикации проверен до фоновой очистки, затем
  точка исчезла из индекса. `node --test infra/integration/live-ai-http.test.mjs`
  проверяет тела HTTP, исключение fallback, ограничение, резерв до
  отправки, usage, отказы и сохранение журнала после перезапуска.
- Yandex. Основной `.env` содержит ключ, каталог, модель генерации и
  обе embedding-модели. Автоматическая проверка разрешений отклонила
  запуск с этим файлом, поскольку изоляция оплачиваемого проекта или
  ключа не подтверждена. Команда не запускалась. Для повторного
  запуска подтвердить назначение существующего каталога и область
  действия ключа в консоли Yandex Cloud.
- OpenAI. Тот же файл содержит ключ, и `GET /v1/models/gpt-6.1-sol`
  вернул 200. `GET /v1/organization/projects?limit=1` вернул 403.
  Требуется подтверждение назначения проекта существующего ключа и
  настройки его лимита владельцем. OpenAI поддерживает
  `Enforce a hard limit` на уровне проекта с возможной задержкой.
- Polza.ai. Найден ключ, публичный каталог подтвердил единственный
  показанный маршрут Alibaba. Ставка записи кеша 297,612 ₽ / 1 млн.
  Маршрут заявляет `max_tokens`. Alibaba документирует для Qwen3.8 Max
  отдельный предел `max_completion_tokens`, включающий chain-of-thought.
  Перед запуском нужно подтверждение от Polza, что этот параметр
  поддерживается выбранным маршрутом. [Документация Alibaba](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-openai-chat-completions)
- Поиск конфигурации выполнен в корнях feature-worktree, основного
  checkout и внешнего worktree, а также в их `src/ai`, `.tmp`,
  `infra/integration` и переменных текущего процесса. `ConfigModule`
  загружает dotenv в dev-режиме. Кампания читает выбранный файл
  отдельно и использует только поля AI-адаптеров.
  [Лимиты OpenAI](https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform) · [Бюджеты Yandex Cloud](https://yandex.cloud/ru/docs/billing/operations/budgets) · [Лимиты Polza.ai](https://polza.ai/for-developers)

При первом запуске каждого провайдера сверить billing, модель и тариф.
Из корня backend `node infra/integration/live-ai-run.mjs report` показывает
локальный журнал. Для разрешённого прогона запускать последовательно
`node infra/integration/live-ai-run.mjs <yandex|openai|polza> <путь-к-dotenv>`.
Флаг `REVIEW_LIVE_AI_SCOPE_CONFIRMED=1` устанавливать после проверки
изоляции проекта или ключа. `REVIEW_LIVE_AI_INITIALIZE=1` допустим только
для первого запуска после сверки предыдущих затрат кампании. Журнал
должен сохраняться между запусками.
Бюджетный ограничитель блокирует новые вызовы по расчётной верхней
границе. Фактические начисления подлежат отдельной сверке с провайдером.
